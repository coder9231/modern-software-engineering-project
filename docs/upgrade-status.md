## 已有实际验证及范围

- 本轮算法、CLI、服务与导出辅助测试：**239 项，233 通过、6 跳过、0 失败**。核心汇总覆盖率为行 **94.31%**、分支 **93.34%**、函数 **98.80%**，超过三项各 90% 的门禁；这是 core 汇总结果，不表示每个文件均达 90%。复查：`npm run test:coverage`；结果保留在 `reports/workspace-coverage-final.txt` 与 `reports/core-coverage.lcov`。
- Windows x64 原生 CLI 已在空 PATH、独立工作目录通过帮助和实际 JSON 检查，两个程序均为未签名产物。记录与 SHA-256 位置见[原生 CLI 交付](native-cli.md#实际验证记录)。macOS/Windows arm64 不记为已测。
- 2026-11-03 在 Windows 完成最后修正后的完整 `npm run verify`，依赖边界、core/ocr/web 类型、ESLint、格式和 239 项测试均实际执行，整体退出码 0。生产构建退出码 0，包含 13 条 API 路由（含质量与流式出题）；已从锁定 npm 依赖准备 16 项本机 OCR 资源，共约 45.6 MiB。日志为 `reports/workspace-verify-final.txt`、`reports/workspace-build-final.txt`。
- 同日 **Edge 桌面与 Chromium 手机模拟共 10/10 项 E2E 通过，用时约 20.0 秒**。覆盖 Go 统计与质量结果、代码行数 2→4 的版本比较及差异 JSON（+2）、两份 ZIP 的统计与 CSV、300 题流式生成/跨页批改，以及错题刷新持久化。报告为 `reports/upgrade-e2e.json`。
- 上述 E2E 还检查首页与功能页手机触控区域至少 48 px、静态画面和高对比度持久化、键盘 Enter 展开显示设置、系统减少动态效果关闭空间动画，以及手机功能页标签文字不溢出。它不覆盖全部键盘操作、读屏或所有配色的 WCAG 对比度。
- 本机 OCR 在真实 Tesseract Worker/WASM 上识别自有印刷样例，检查没有图片上传或跨站资源请求。`9 - 3 = 6` 被转录成 `9 - 3 = 60`，人工修正、重新确认后得到 2/2 正确。这证明识别后的复核与批改流程，不证明原始转录逐字准确；其他印刷版式及真实手写仍需独立验收。
- 生产产物通过实际 Wrangler 入口在本地 5181 启动，**9 项 HTTP 检查全部 200**：主页、健康、数学配置、OCR Worker/模型 HEAD、Go 统计、质量分析、3 题普通生成、300 题流式生成。同时核对 Go 为 2 代码/1 注释/1 空白行、质量文件、种子卷与流式完成；记录为 `reports/production-smoke-results.json`。这不是 Docker 或云环境运行结果。

以上证据对应本轮 Windows 工作区与列明的本地环境。覆盖率、浏览器 JSON/截图与构建产物保留在被忽略的本地输出目录，不随源码提交个人作业或完整运行产物；后续源码变化需要重新运行相关检查。
