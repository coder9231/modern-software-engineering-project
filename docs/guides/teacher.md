# 教师使用指南

本文对应当前仓库版本；[现有演示站](https://se-practice-coder9231.a0910663736.chatgpt.site)可能仍运行旧版。本地启动方法见[首页](../../README.md)。

## 制作一份练习

1. 从导航进入“四则运算”，选择“出题与练习”。
2. 在“教学参考模板”选择合适示例：小学一至六年级或“初中口算 · 有理数”，共 7 组。名称仅供备课参考，可继续调整，不代表官方课标或学生能力评级。
3. 设置“题目数量”，也可点“周练 300 题”。根据教学目标调整操作数、运算符数量、括号、负数、分数与答案范围。
4. 如需复现同一份卷，在高级选项填写固定随机种子，并保留完整规则。相同规则与种子在同一算法版本下生成相同题目。
5. 点“生成练习”。完成后核对题目与范围；修改左侧设置不会追溯修改已生成的卷，需再次生成才生效。

单次题量为 1～10000。300 题及以上分批生成并显示进度；可取消，取消或失败时保留原卷，不把不完整预览当成正式试卷。若提示题目不足或超时，减少题量、扩大操作数/答案范围，或增加运算符。

余数题需要仅选除法、1 个运算符、非负整数，关闭分数与负数。答案采用“商 R 余数”，例如 7 ÷ 3 的答案为 2 R 1。分数以精确有理数批改，等值分数和等值有限小数可以判为相等。

## 打印试卷与独立答案卷

1. 生成题目后，在“带走这张练习纸”填写“试卷标题”“班级（可留空）”“页脚提示（可选）”。
2. 选择 1～4 列与合适行间距。给学生的卷可不勾选“附答案”。
3. 点“试卷 / PDF”，在浏览器或系统打印窗口检查纸张、方向、页边距和分页，再选择打印机或“另存为 PDF”。
4. 点“独立答案卷 / PDF”，再次在打印窗口保存，得到单独的答案文件。
5. 留档时可点“题目 JSON”或“题目与答案 JSON”；后者包含标准答案，应按用途分发。

打印覆盖整份练习，不限于当前屏幕页。PDF 由浏览器打印生成，本站不提供服务器下载链接；标题、班级与页脚只用于当前浏览器打印，不上传。这些设置和当前作答不会作为完整草稿永久保存，刷新前先导出需要的文件。实际分页与字体效果需在目标浏览器和打印机中预览。

## 批改与错题复习

学生可在网页作答后点“提交整卷批改”。服务器从算式重新计算标准答案，不信任客户端传来的标准答案；未作答也会在结果中标明。批改后可看正确率、“只看错题”与解析。

“错题本”在当前浏览器保留最多 500 道原题，可按运算符、粗略难度和状态筛选；点“重练筛选结果”“重练选中”或“重练此题”后，回到练习页作答并批改。答对的已收录原题标为“已掌握”，以后再次答错会回到“待订正”。它不是老师可远程查看的班级数据库；公共电脑上应提醒学生清理自己的记录。

## 汇总代码作业

此功能统计源码规模，不批改数学作业，也不能直接据代码行数评价成绩。

1. 请每位学生提交一份普通 ZIP，名称可用无敏感信息的作业编号。不要把密码、令牌、个人资料或整个依赖目录打包。
2. 进入“代码统计”，找到“班级作业汇总”，点“选择学生作业 ZIP”，一次最多选择 20 份；选择后开始逐份处理。
3. 等待每行的文件数、代码行和状态；检查“跳过”和异常。单份失败不会使已经完成的汇总行消失。
4. 需要中断时点“取消批量统计”，已完成行仍可导出。
5. 点“导出全班汇总 CSV”，用表格软件查看。行数只是规模指标，请结合功能、测试、评审与个人贡献证据评价。

每份 ZIP 压缩后最多 4 MiB，展开最多 8 MiB、200 个条目、目录深度最多 32。仅支持普通 ZIP，不支持加密、链接、多卷或 ZIP64。压缩包在浏览器解包，符合条件的源码按批发送到本站统计接口；ZIP 文件名用于本地汇总名称，不作为源代码持久保存。导出的 CSV 可能包含本地作业名，请自行保管。

## 使用 OCR 的边界

“拍照改卷”默认提供“本机印刷体”：用于清晰的印刷算式，无需 AI 密钥，图片留在本机。Tesseract 不适合可靠识别手写；复杂版式、模糊图片、分数线和乘除符号都可能误识别，必须逐行人工核对。

“可选 AI 服务”需要维护者配置密钥与访问码；点“上传并识别”后图片经本站发给 OpenAI。识别完成后校正文本，勾选“我已逐行核对识别内容”，再点“批改录入内容”。真实手写准确率与可选服务需独立验收，入口可见不代表识别效果已验证。也可完全手动输入“算式 = 答案”。

## 保留与清理

本站没有教师账号、学生账号、云端题库或跨设备同步。练习记录、错题和榜单都与当前浏览器及站点地址绑定；本机 localhost 与线上站点的数据互不共享。浏览器清理站点数据、隐私模式结束或更换设备可能使记录丢失。更多细节见[常见问题](faq.md)。
