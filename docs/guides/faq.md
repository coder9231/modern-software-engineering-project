# 常见问题

## 为什么线上看不到新功能？

本轮按约定保留[现有线上站点](https://se-practice-coder9231.a0910663736.chatgpt.site)，交付源码、CI 和 Docker 配置，不自动部署。用当前仓库本地运行查看新功能。提交、CI 通过、容器启动与线上发布分别需要证据。

## 应该在根目录还是 website 安装？

在根目录运行 npm ci，要求 Node.js ≥22.22.1。四个 npm 工作区共用一个根锁文件；packages/ 是业务实现来源。website/ 与 tools/ 保留历史兼容用途，旧记录中的独立安装步骤不适用于本轮工程结构。

## 题目为什么生成失败或很慢？

限制太窄时题空间可能不足；比如操作数仅有几个数，却要求上千道结构不同的题。减少题量、扩大操作数和答案范围，或增加运算符。余数模式只允许非负整数的一次除法，不可同时开分数或负数。

300 题及以上按最多 32 题一块生成；服务器设 30 秒期限，客户端也会超时。进度预览不等于完整试卷。取消或失败时保留原卷；重新生成成功后才替换。最多 10000 题是一次任务限制，不是并发容量承诺。

## 预设年级就是学校课标吗？

不是。7 组“教学参考模板”是小学一至六年级与初中有理数的可编辑示例，教师需按教材和学生情况调整。错题难度也只是规则分类，不评价学生能力。

## 为什么 0.5 和 1/2 都对？余数怎么填？

核心用精确有理数运算，按数值比较等值分数和有限小数，不用浮点近似判等。余数题写“商 R 余数”，例如 7 ÷ 3 = 2 R 1，仅适用于非负整数单次除法。

## PDF 在哪里下载？

点“试卷 / PDF”或“独立答案卷 / PDF”后，在浏览器/系统打印窗口选“另存为 PDF”。这是本地打印，不是服务器生成下载链接。试卷覆盖整份题目；列数、行距、标题、班级和页脚应在打印预览确认，实际分页需要目标浏览器验收。

## 会保存哪些数据？刷新后还能继续吗？

| 数据                                                                        | 保存位置与期限                                   | 清理方式                         |
| --------------------------------------------------------------------------- | ------------------------------------------------ | -------------------------------- |
| 当前题目、逐题答案、统计完整报告、质量结果、导入的比较报告、OCR 文本/访问码 | 当前页面内存；刷新/关闭可能丢失                  | 关闭或刷新页面；需要结果先导出   |
| 数学练习摘要                                                                | 当前浏览器 localStorage，最多 50 条              | “练习记录”中删除单条或“清空记录” |
| 错题原题、提交答案与状态                                                    | 当前浏览器 localStorage，最多 500 道             | “错题本”删除单题或“删除选中”     |
| 24 点无提示成绩                                                             | 当前浏览器 localStorage，最多 30 项              | “本地挑战榜”删除记录             |
| 最近代码统计                                                                | 当前浏览器 localStorage，最多 4 条摘要，不含源码 | “最近统计”的清空入口             |
| 高对比度、静态画面                                                          | 当前浏览器 localStorage                          | 修改“显示设置”，或清除本站数据   |
| 开场已播放、导航动画暂停状态                                                | 当前标签页 sessionStorage                        | 关闭标签页或清除本站数据         |
| 导出 JSON、CSV、PDF                                                         | 自己的下载目录/选择的文件位置                    | 在本机管理文件                   |

没有账号或云同步。localhost、其他端口与线上域名的数据各自隔离；隐私模式、浏览器配额或关闭存储权限会影响保留。出现本地存储提示时，当前练习仍可继续，但刷新后记录可能不在。清空练习摘要不会同时清空错题本或榜单。要全部移除，可在浏览器的本站设置中清除站点数据；这会一并删除偏好与其他本地记录。

## 代码、作业和图片会上传吗？

选择文件本身不上传。点“开始统计”后，源码按批发给本站统计服务；点“分析所选源码质量”会另外发送所选源码。服务不执行源码、不将其持久保存；完整报告留在页面会话中。小报告导出可发送统计报告到本站格式化，大报告与差异导出在浏览器生成。

班级 ZIP 在浏览器解包，源码发送到同一统计接口；作业名用于本地汇总。数学出题发送规则，批改发送算式与作答；本地错题本不会整本自动上传，重练提交时会发送本次题目。

本机 OCR 图片只在设备内处理，运行资源从本站读取；批改时把核对后的文本发给本站。只有选择“可选 AI 服务”并点击“上传并识别”才会把图片经本站发给 OpenAI。不能把“本地保存记录”理解成“所有功能都完全离线”。

## 本机 OCR 不能用怎么办？

先让维护者在根目录运行 npm ci 与 npm run ocr:prepare，再在面板点“重新检查资源或服务”。使用 4 MiB 以内的 PNG/JPEG/WebP，本机模式还限制 1200 万像素。资源、浏览器图像解码、内存或超时都可能导致失败；可取消后裁剪清晰区域重试，或直接手动输入。

Tesseract 主要用于清晰印刷体，**不适合可靠手写识别**。即使是印刷算式，也可能多字、漏字或把符号识错。必须逐行校正，勾选人工核对后再批改；这一步通过不证明 OCR 原始转录准确。

## 可选 AI 显示未配置，影响其他功能吗？

不影响本机识别、手动录入与数学批改。AI 模式需要维护者提供服务端密钥和识别访问码；不要把服务端 API 密钥填到访问码框。配置状态只说明应用读到配置，真实调用、费用、延迟和手写效果需要另外验收。

## 统计口径与质量指标可信吗？

总行数 = 代码行 + 注释行 + 空白行，按物理行统计；混合代码与注释的行计代码，末尾换行不额外加行。JS/TS 有限预算内用解析器，超预算或无法解析时回退扫描；不展开宏，不执行代码，也不等同于编译器。JSX/TSX、SCSS 等仍不在支持范围。

复杂度是教学用文件级词法估计，不是完整 McCabe 控制流分析；重复率来自规范化片段，不是语义等价或抄袭检测。JSON 报告比较按路径与行数识别变化，等行数修改无法发现，重命名通常显示为删除加新增。请结合阅读源码与测试判断。

## ZIP 为什么被拒绝？

一次最多 20 份，每份压缩 4 MiB、展开 8 MiB、200 个条目、32 层深度。加密、符号链接、多卷、ZIP64、损坏或危险路径会拒绝；请使用普通 ZIP，仅打包自有源码，去掉依赖和构建目录。取消后已完成行仍可导出；异常行不表示作业代码已经全部成功统计。

## 高对比度或静态画面在哪里？

展开“显示设置”切换。“静态画面”会保留主要功能，系统减少动态效果设置始终优先，低性能设备可能默认静态。若出现“这个工作空间遇到了一点问题”，点“重新打开页面”；已保存本地记录不会因刷新被主动删除，未保存的当前输入可能丢失。

## 有 Dockerfile 和 E2E 就算验收完成了吗？

不是。本轮机器没有 Docker 命令，尚未完成容器实跑。Docker 配置要在目标机器实际构建、启动、查看健康状态与页面。E2E 要看对应提交的真实运行结果；Chromium 手机视口不代表实体手机、Safari 或 Firefox。真实打印、真实印刷体、可选 AI、手写样本与跨浏览器分别记录，不能用一次模拟测试替代。
