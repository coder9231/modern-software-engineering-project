## 邀请成员加入私有仓库

仓库所有者可在 GitHub 仓库的 **Settings → Collaborators**（界面也可能显示 **Collaborators and teams**）中添加成员，输入对方的 GitHub 用户名并发送邀请。成员接受邀请后获得仓库访问权限；仅分享仓库链接不会授予访问权限。

如后续迁入组织仓库，可按组织的团队与角色安排权限。具体协作流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
