# 决策 0004：原创胶片意象的可跳过开场

日期：2026-10-16。状态：已实现并随网站第 3 版发布，官方生产构建成功；本地浏览器已检查桌面与窄屏画面及主要关闭、重播流程，线上已核对首次片头与重播。

## 目标与视觉选择

根据用户希望加入经典电影氛围开场动画的要求，采用原创胶片引导带、倒计时、画框、轨道和片名字卡，展示 SE Lab 的“构建、学习、改进”主题。视觉由本地 HTML、CSS 和内联 SVG 组成，没有引用外部电影片段、海报、角色、制片厂标识或音乐，也不播放声音。

开场是展示体验的一层，不能影响用户进入代码统计、四则运算和已有练习。为此使用原生 `dialog`，默认保持关闭，客户端完成水合后才按条件打开；没有 JavaScript、浏览器不支持 `showModal` 或打开失败时，原页面仍可使用。

## 播放与关闭

首次普通访问播放约 4.8 秒，始终提供“跳过片头”按钮，并允许 Escape 关闭。定时结束、按钮、Escape、页面隐藏、页面离开和 hash 导航共用清理路径，关闭后恢复页面滚动。使用 `requestAnimationFrame` 依据实际时间计算结束，不依赖动画事件是否一定触发。

通过 `sessionStorage` 记录当前会话已展示，刷新或在同一会话中继续使用时不重复自动播放；本模块内存状态作为存储不可用时的回退。会话标记不保证跨浏览器或所有新标签页永久共享。带有 hash 的直达链接（例如 `#math`）跳过首次自动开场，让用户直接进入目标功能。

页头提供“重播片头”。重播只重新打开展示层，不重新挂载数学工作区，不清空题目、作答或练习历史。`dialog` 打开后焦点进入跳过按钮，退出时恢复进入前的焦点；重播按钮使用 `aria-expanded` 表达状态，保留可返回的焦点目标。

## 减少动态效果

代码检查系统的 `prefers-reduced-motion: reduce`：首次访问直接跳过自动开场；用户主动重播时展示静态字卡，约 3.2 秒后关闭，仍可提前退出。播放期间若系统偏好改为减少动态效果，立即关闭。

以上是已实现的分支与样式规则。本轮没有在浏览器中模拟或切换该系统偏好，不能标为实机验收通过。此项仍需后续使用真实偏好设置核对。

## 本地浏览器验证与修复

在本地开发站点以约 971×884 和 390×844 的视口检查，片头字卡、跳过入口与边框布局正常。已实际核对跳过、Escape、自动结束、刷新后不重复播放和手动重播；关闭后可继续操作网站。重播前后的练习输入 `['3', '0', '']` 保持一致。

浏览器检查中发现并修复了两个展示问题：

- 倒计时使用 `animation-fill-mode: both` 时，延迟阶段的 3、2、1 数字重叠。改为 `forwards`，避免尚未开始的数字提前显示。
- 场景的 `overflow: hidden` 形成可被焦点滚动的容器，曾出现 `scrollTop=361` 导致画面裁切。改为 `overflow: clip`，后续实际检查场景 `scrollTop=0`，画面正常。

另将重播按钮的禁用状态改为 `aria-expanded`，避免动画退场时无法把焦点返回按钮。以上属于真实浏览器操作发现的问题与修复，不以截图代替功能测试。

本地截图为 `reports/cinematic-opening.jpg` 和 `reports/mobile.jpg`，仅用于本地检查；它们没有随公开源码分发。
