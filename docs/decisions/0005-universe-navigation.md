# 决策 0005：以星图组织功能的工程宇宙

更新日期：2026-10-17。状态：已实现并发布网站第 4 版，本地验证、生产构建、线上 HTTP 回归与已记录的线上浏览器检查完成；代码已推送 GitHub，对应代码提交 CI 全部通过。本决策记录本轮范围与设计取舍；实际构建、浏览器与发布结果分别记录于[宇宙导航验证记录](../universe-test-results.md)，不由本文件推断通过。

## 用户目标与本轮范围

用户提出“将整个网页比为一个宇宙，里面的选项归为星球”，并要求继续创作。本轮把这一概念落实为可以操作的星图首页、功能星球入口、进入功能时的镜头过渡，以及与星图一致的开场与界面风格。现有代码统计、四则运算、工程实践和项目说明继续作为真实功能页面；已有题目、作答和统计结果不能因浏览星图或重播开场而丢失。

星球承担有文字说明的导航入口。视觉意象用于帮助识别功能，不改变题目生成、数学批改、代码分类和服务端接口的规则。个人主页可以展示真实项目成果，但姓名、经历、头像和团队分工尚待用户提供，不填入虚构身份或成绩。

## 视觉实现与依赖选择

使用原生 HTML、CSS 与 SVG 表现分层星空、光晕、星球、轨道和镜头缩放，形成轻量的 2.5D 空间感。本轮不引入 WebGL 或新的图形库，也不把 CSS 透视与渐变宣传为真实三维物理场景。这样可沿用现有 React/Vinext 构建、减少首次下载和渲染负担，并将功能界面与装饰层分离。

星空装饰对辅助技术隐藏，不承载必要文本。功能名称与简短描述始终用页面文字呈现，用户无需辨认颜色、观察运动或理解星球造型才能进入功能。内容区维持可阅读的对比度和清楚的操作按钮。

## 导航、直达与状态保留

星图是首页与全局返回目标。无 hash 默认显示星图，`#overview` 是显式星图入口；已有 `#counter`、`#math`、`#practice` 和 `#about` 入口保持兼容，新增 `#profile` 显示起源星。未知 hash 回到星图。实现以同一个页面状态组织这些区域，仍需在验证记录中核对刷新、地址栏直达和前进后退行为。

| 星球 | 功能区域 | 直达入口 |
| --- | --- | --- |
| 数据星 | 代码量统计、语言分布与报告 | `#counter` |
| 逻辑星 | 四则运算、练习批改与 24 点 | `#math` |
| 建造星 | 需求、设计、复用和验证的工程说明 | `#practice` |
| 起源星 | 已知 GitHub 账号与课程项目作品 | `#profile` |
| 档案星 | 项目背景、开源仓库与协作说明 | `#about` |

星球选择使用可通过键盘聚焦和激活的原生交互元素，保留中文可访问名称与明显的焦点样式。进入功能时的装饰过渡不成为访问前提；减少动态效果时直接切换。全局提供文字导航与“返回星图”入口，窄屏可以通过自然排版的星球入口进入功能，无需精确点击移动中的目标。

`MathWorkspace` 持续挂载，页面切换只改变其可见状态，避免生成题目、输入内容、当前模式和计时被重新初始化。代码统计结果继续由上层页面状态持有。转场是视觉层，不在完成动画的回调中重新创建业务数据。

本地与第 4 版线上浏览器均已验证练习往返保留。线上还验证了主动重播片头后 Escape 退出，再往返星图的路径：3 道题和已填答案保留、计时继续显示。验证记录中的计时观察仅证明未重置，不作为准确性测量。

星球点击到功能切换之间约有 650 ms 的视觉过渡。用户在此期间仍可返回星图，因此父页面为每次导航递增星图访问标识，重新挂载星图并清理旧定时器，避免已经取消的导航在稍后重新打开功能页。此取消路径已通过本地浏览器重演，详见验证记录。

## 开场与可访问性

将原有电影感开场升级为宇宙苏醒与星系揭晓，使片头与星图共享主题。继续保留跳过、Escape、自动结束、同一会话不重复自动播放和手动重播；带功能 hash 的直达访问避免等待片头。重播不离开当前功能、不重置练习。

系统设置为 `prefers-reduced-motion: reduce` 时，停止持续漂移、旋转、视差与镜头缩放，首次自动片头沿用跳过策略；用户主动重播的静态呈现以实际实现为准。不能用“已有媒体查询”替代浏览器的真实减少动态效果验收。

## 个人展示的数据边界

起源星展示已知的公开 GitHub 用户名 `coder9231`、其 GitHub 链接，以及本站真实的代码统计、四则运算和工程实践三个作品入口。页面明确说明个人介绍、成员职责和更多作品随项目补充，不推断姓名、学校、经历、头像照片和其他社交账号。本轮不提供个人资料编辑或云同步，不将团队课程项目伪装成已经核实的个人履历。

## 工程取舍与验收

本轮先完成可访问、可返回、可直达、保留业务状态的导航，再细化动画效果。星图、片头与业务核心分离，不增加外部影视素材、自动播放音乐或 AI 调用。未配置的 AI OCR 仍保持明确的未配置状态。

验收至少覆盖桌面与窄屏布局、全部星球入口、文字导航、hash 直达与历史返回、键盘焦点、减少动态效果、跳过与重播，以及四则运算和代码统计回归。生产构建、API 测试、浏览器交互和线上发布分别留存证据；任何一项通过不能替代其他项。

本轮已事前记录范围与验收条件，未承诺完整工时或性能指标。后续以实测结果记录修改与剩余工作，不补写无法追溯的时间。
