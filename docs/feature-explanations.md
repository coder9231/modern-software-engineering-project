# 逐行统计解释与算式分步讲解

## JavaScript 逐行统计解释

在“代码统计”选择源码后，找到“每一行，为什么这样统计？”，选择一个 `.js`、`.mjs` 或 `.cjs` 文件，点击“逐行解释”。每行同时显示行号、文字分类与源码；点击行号查看判断依据。每页最多显示 50 行。

统计口径与普通统计一致：代码、纯注释、空白三类互斥；混合行归代码；空白行始终归空白；末尾换行不额外增加一行。字符串、模板文本和正则中的注释符号按代码处理。可用以下例子观察分类：

```js
const url = "https://example.com";
// 说明

let value = 1; // 混合行
```

预期总行数 4，代码 2、注释 1、空白 1。第一行的双斜线位于字符串内部；第四行含代码，因此按代码计入一次。

逐行解释复用核心 `explainJavaScript` 和普通统计中的解析器、回退扫描器。语法无法解析时页面明确提示尽力分类。原文件最多 128 KiB，解码后 UTF-8 最多 64 KiB；更大的文件仍可使用普通统计。支持现有 BOM 与编码设置、排除规则和扩展名筛选。点击按钮会发送所选文件到本站，源码不执行、不持久保存。

接口 `POST /api/code-count/explain` 接受普通统计格式的 `files`、`options`，其中 `files` 必须恰好包含一个 JavaScript 文件。返回文件路径、总计、逐行分类、原因编码及 parser/scanner 方法。

## 四则运算分步讲解

生成练习后点击题目旁的“解析”。初始只显示算式，点击“提示下一步”查看待计算的子式，再点击“显示这一步”展开结果。可直接显示全部步骤，或用“重新提示”从头开始。Escape 关闭对话框；Tab 可在关闭、提示、展开及原理入口间移动。

例如 `8 + 12 ÷ 3`：第一步 `12 ÷ 3 = 4`，算式变为 `8 + 4`；第二步结果为 `12`。`(8 + 12) ÷ 4` 则先计算括号内的加法。额外括号用于明确运算结构，不改变题意。

核心 `explainExpression` 复用已有表达式解析器和精确有理数运算，按表达式结构依次计算子式，记录计算前后算式。支持负数、精确分数结果与有限小数；目前讲解展示子式运算及约分后的结果，不展开通分、进位或竖式教学过程。带余数题单独展示整数商、余数及乘加验算，保持与批改格式一致。

`POST /api/math/evaluate` 增加可选 `steps: true` 和 `kind: normal/remainder`，返回 `initial`、`answer`、`rpn`、`steps`。不传 steps 时保留原有求值响应格式。题目生成与批改仍使用原有流程。

## 验收样例

- 网址与正则中的注释符号不计为注释；混合行归代码，空文件为零行。
- 同一文件的逐行汇总与普通统计相等；切换文件或编码后不展示旧解释。
- 源码超过 50 行可翻页；无法解析的源码显示回退提示；超过解释上限得到明确错误。
- `8 + 12 ÷ 3 = 12`，`(8 + 12) ÷ 4 = 5`。
- `20 ÷ 2 ÷ 5 = 2`，`10 - 3 - 2 = 5`，保持同级运算顺序。
- `1/3 + 1/6 = 1/2`，`0.1 + 0.2 = 3/10`；使用精确结果。
- 余数模式 `7 ÷ 3 = 2 R 1`，验算 `3 × 2 + 1 = 7`。
- 初始及提示阶段隐藏最终结果；展开、重新提示、键盘关闭均可操作。
