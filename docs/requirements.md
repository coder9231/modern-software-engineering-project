## 统计工具首版范围

输入代码文件或项目目录，按语言展示总行数、代码行、注释行和空白行，使用 `--details` 展示文件明细。目录模式默认排除依赖、版本库和构建产物，支持自定义排除与扩展名过滤，可导出 JSON/CSV。详细默认排除项已在工具说明中列出。

## 首版验收条件

| 场景 | 建议的验收结果 |
| --- | --- |
| 支持语言的示例文件 | 各项统计与已人工确认的预期一致 |
| 含多个受支持文件的目录 | 文件明细与汇总一致，按约定规则排除文件 |
| 空文件 | 各项行数为零 |
| 多行注释、代码与注释混合、字符串中的注释符号 | 按现行物理行分类规则处理，并用固定样例验证 |
| 不支持的文件或读取失败 | 明确说明跳过或失败原因，避免生成误导性统计 |
| 同一输入重复分析 | 在相同配置下得到一致结果 |

- 多行注释内的空白行归入哪一类？
- 字符串里的注释符号、转义字符和语言特有语法如何处理？
- 哪些扩展名、编码和换行格式属于首版支持范围？

以上问题在首版中已有具体选择，详见工具说明；后续调整规则时记录决定和理由，并同步更新可手动核对的输入与预期输出。代码量不作为个人贡献或代码质量的单一评价依据。

## 四则运算本轮范围

默认生成 20 道题，每题 2 个运算符，使用加减法，整数操作数 0～100，最终答案 0～100；支持老师调整为 300 道或最多 10000 道。可调整范围、运算符、括号、负数、分数与除法模式。结构去重合并加法、乘法交换与结合变形；固定种子可复现，题空间不足明确报错。

网页提供练习、批改、计时、本机浏览器历史、双语、打印与 JSON 导出；24 点共享数学求值模块。批改由后端根据表达式重新计算，前端附带标准答案不具有权威性。AI 负责图片转录，人工可校正，再交数学核心批改；本轮未配置真实识别密钥，未验证真实手写图片。

核心、服务、CLI 与 OCR 适配器已编写，数学 43 项自动测试通过；OCR 采用模拟响应，不能代替真实识别。整站联合单元测试 124 项中 119 项通过、5 项因平台条件跳过、0 项失败。全站类型与应用 lint 检查通过，2026-10-16 官方生产构建成功并发布网站第 3 版，本地与线上真实 HTTP 均为 14 项通过。浏览器已核对基础出题、批改、历史、英文、24 点和片头流程；打印、下载、完整窄屏操作、减少动态系统偏好以及新版本 GitHub CI 仍需分别验收，见[验证记录](arithmetic-test-results.md)。服务无状态，历史不跨设备，没有账号、班级或教师成绩册。

## 服务规模与估时

课程图片中的 10000 个不重复算式、每日 10000 名学生、上万用户同时访问需要分别验收。本轮提供受控的原生 fetch 负载脚本，默认只面向本机；本地开发服务已完成 5 并发、100 请求、每请求 20 题的短时测量，100 请求全部成功。未执行万级并发测试，也没有可据此承诺的 SLA。下一阶段应明确高峰时段、请求频率、典型题量、延迟及错误率目标，再进行授权环境中的容量实验。

课堂图片没有给出实际工期和任务分工。本轮未事先记录完整估时，不补写虚构时间；后续迭代在任务开始前记录范围、假设与预计工时，再对照实际结果复盘。
