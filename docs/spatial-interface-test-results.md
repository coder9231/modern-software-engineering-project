- 首页改为紫黑色透视十字网格、带发光侧边的等距平台与持续旋转的双层圆环；平台、底座、几何模块和文字入口逐步呈现。

- 使用 CSS/SVG 绘制，无新增依赖或外部视频。暂停、减少动态效果、页面隐藏和离开视口的处理已实现；减少动态效果及隐藏策略本次仅作代码检查。
