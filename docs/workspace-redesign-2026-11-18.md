# 工作区界面改版 · 2026-11-18

## 当前范围

- 首页开场在当前标签页会话中播放一次，约 4.2 秒后保留静态背景。系统减少动态效果及站点静态画面设置优先。
- 首页中央保留代码统计、四则运算、工程实践、关于项目四个入口。个人主页入口、内容组件和专属样式已按用户要求移除；旧个人主页地址和其他未知 hash 返回首页。后续资料另行补充。
- 工作区侧栏不再列出与当前主功能并列的其他主页功能，使用返回主页切换工作区。
- 代码统计主界面保留源码选择和必要选项，完成后进入 `#counter/results` 独立报告视图。批量统计、质量分析、版本对比、最近统计和规则说明为侧栏子功能。报告和源文件仅在当前页面内存中保留，刷新后需重新统计；本地历史仅保存摘要。
- 四则运算生成后自动打开练习小窗。打印与 JSON 导出放在“带走这张答题纸”小窗。关闭小窗或相互切换保留当前作答和打印设置，支持 Esc、关闭按钮和背景关闭。解析使用叠加小窗，关闭后恢复题目按钮焦点。打印前退出小窗，打印调用结束后返回导出小窗。
